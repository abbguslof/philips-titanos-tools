# Code of Conduct

Be civil. This is a hardware research project; disagreement about technical
claims is expected, but harassment, doxxing, and sharing another person's device
identifiers or credentials are not acceptable.

## Expected behaviour

- Critique claims with evidence and reproducible steps.
- Respect ownership and local law. Do not help someone attack a device they do
  not own.
- Redact serial numbers, MAC addresses, SSIDs, IP addresses, pairing data, and
  private keys before posting logs.
- Assume good faith and ask for clarification before escalating.

## Unacceptable behaviour

- Publishing another person's private data or credentials.
- Encouraging remote abuse, botnet use, or bypassing content protection.
- Harassment, threats, or discriminatory language.

Maintainers may remove issues, comments, or contributions that violate these
rules. Report problems through the repository profile or a private security
advisory.
