# Document firmware acquisition, do not redistribute firmware

The vendor package is 1.5 GB, proprietary, and model-specific. We will document the official support-page path, the historical candidate-URL probing, and the recorded hashes, but we will not commit the package or extracted vendor filesystems.

**Status:** accepted

**Consequences:** Users must obtain their own package and verify the hash. The repository stays small and avoids redistributing vendor code. The extraction tool works from a user-supplied package.
