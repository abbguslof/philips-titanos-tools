# Community

Use [GitHub Discussions](https://github.com/abbguslof/philips-titanos-tools/discussions)
for questions, model reports, ideas, and show-and-tell. Start with the
[welcome discussion](https://github.com/abbguslof/philips-titanos-tools/discussions/7). Use
[issues](https://github.com/abbguslof/philips-titanos-tools/issues/new/choose)
for reproducible bugs and formal field reports.

## Where to post

| Topic | Place |
| :--- | :--- |
| "Does this work on my model?" | [Discussions](https://github.com/abbguslof/philips-titanos-tools/discussions) or a [field report](https://github.com/abbguslof/philips-titanos-tools/issues/new/choose) |
| A new model, firmware, or port surface | [Field report](https://github.com/abbguslof/philips-titanos-tools/issues/new/choose) |
| A tool bug or parsing failure | [Issue](https://github.com/abbguslof/philips-titanos-tools/issues/new/choose) |
| A correction to a research note | Pull request or issue |
| A question about a procedure | [Discussions](https://github.com/abbguslof/philips-titanos-tools/discussions) |
| A security concern | [SECURITY.md](https://github.com/abbguslof/philips-titanos-tools/blob/main/SECURITY.md), not a public issue |

## Before posting

- Name the model, chassis, and firmware. Exact strings matter.
- Say whether the unit is on stock firmware and whether you can restore it.
- Use read-only probes on field units. No boot-chain writes on someone else's
  TV.
- Redact serials, MACs, SSIDs, IPs, PINs, pairing credentials, and vendor
  firmware.
- Do not post remote exploit requests, DRM bypass requests, or cloud bypass
  requests. This project is owner-authorized local root and research.

## Support boundary

The verified path is the `55PUS8000/12`. Other models are external reports.
A report on one build does not prove another build. The project can help you
read the evidence, not promise a root path on an untested unit.
