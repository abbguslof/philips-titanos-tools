## How the project is organized

- `docs/guides/` contains task-first procedures.
- `docs/research/` contains the evidence and status-labeled findings.
- `docs/reference/` contains formats, partition maps, and vocabulary.
- `evidence/` contains the redacted proof runs.
- `tools/` and `payloads/` contain the local tooling.

The root [README](https://github.com/abbguslof/philips-titanos-tools#readme)
is the GitHub front door. This site is the searchable reference.
